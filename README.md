
# HoverView

**HoverView** — это легковесная утилита для Windows 10/11, которая показывает предпросмотр файлов прямо в Проводнике при наведении курсора. Больше не нужно открывать файл, чтобы понять, что внутри — достаточно просто задержать курсор над ним.

## ✨ Возможности

- **Изображения**: JPG, PNG, BMP, GIF (с поддержкой анимации), WebP.
- **Видео**: MP4, AVI, MKV, MOV, WMV (с воспроизведением без звука).
- **Аудио**: MP3, WAV, FLAC, AAC, OGG, M4A (с регулировкой громкости и отображением битрейта).
- **Текст и код**: TXT, LOG, JSON, XML, CSV, MD, INI, CONFIG, а также исходный код (`.cs`, `.cpp`, `.py`, `.js`, `.html`, `.css` и др.).
- **Архивы**: ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ — с отображением содержимого в виде дерева (папки и файлы).
- **Информация о файле**: в нижней панели отображается разрешение, вес, длительность и битрейт (для аудио), количество файлов в архиве.
- **Умное позиционирование**: окно автоматически подстраивается под границы монитора (поддержка нескольких дисплеев и DPI).
- **Гибкие настройки**:
  - Размер окна предпросмотра и режим подстройки под контент (с минимальной рамкой или без).
  - Задержка появления и исчезновения окна (в миллисекундах).
  - Настройка поддерживаемых форматов (изображения, видео, аудио, текст, архивы).
  - Максимальный размер файла для предпросмотра.
  - Максимальное количество записей в архиве и строк текста (0 = без ограничений).
  - Размер кэша изображений (по количеству и по весу в МБ).
  - Регулировка громкости аудио.
  - Автозапуск при старте Windows.
  - Выбор языка интерфейса (русский / английский).
  - Настройка поведения при полноэкранных приложениях (для оптимизации).
- **Иконка в трее** с быстрым доступом к настройкам и выходу.
- **Удержание окна** для текстовых файлов и архивов: если навести курсор на окно предпросмотра, оно не исчезнет, позволяя прокручивать текст или дерево архива.

## 🚀 Установка и запуск

### Требования
- Windows 10 или Windows 11 (x64).
- [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).
- Обязательно должно быть включено отображение расширений файлов, без него программа работать не будет!

### Сборка из исходников
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/moonsoir/HoverView.git
   cd HoverView
   ```
2. Соберите проект:
   ```bash
   dotnet build -c Release
   ```
3. Запустите исполняемый файл из папки `bin\Release\net8.0-windows\`.

### Готовые сборки
Готовые `.exe` файлы можно найти в разделе [Releases](https://github.com/moonsoir/HoverView/releases).

## 🛠 Использование

1. Запустите `HoverView.exe`. Программа свернётся в системный трей (возле часов).
2. Откройте Проводник Windows и наведите курсор на файл.
3. Через заданную задержку (по умолчанию 300 мс) появится окно предпросмотра.
4. Чтобы изменить настройки, щёлкните правой кнопкой мыши по иконке в трее и выберите **«Настройки...»**.

### Настройки
Все параметры сохраняются в `%AppData%\HoverView\settings.json` и применяются автоматически.
