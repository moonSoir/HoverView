# HoverView
Простая программа для предпросмотра изображений, видео, аудио и текстовых файлов на Windows 11.


Возможности:

  - Предпросмотр файлов различных форматов(Видео, аудио, фото и текстовых)
  - Гибкие настройки поведения программы
  - Работает во всех вкладках проводника Windows 11
  - Поддержка многомониторных систем
  - Кэширование файлов
  - Автозапуск
  - Показ основных характеристик файла при предпросмотре


Благодарности:

**[QtTabBar](https://github.com/indiff/qttabbar)** - идейный вдохновитель

**[kyosora](https://github.com/kyosora)** - основа для логики определения файла на который наведён курсор взята из **[HoverPeek](https://github.com/kyosora/HoverPeek)**

**[AnimatedImage.Wpf](https://github.com/whistyun/AnimatedImage)** - библиотека для отображения анимированных изображений.
